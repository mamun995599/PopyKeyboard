# পপি কিবোর্ড — টাইপিং ম্যানুয়াল

সব হরফ ছোট হাতের ধরেই টাইপ হয়। বাংলা মোডে শিফট কী-র নাম **যুক্ত**; **একবার ট্যাপ** করলে "স্বয়ংক্রিয় মিলন নয়" টোকেন যোগ হয় (৪ নম্বর)। এই ম্যানুয়ালে `⇧` মানে ওই ট্যাপ। অটো কারেক্ট চালু থাকলে স্পেস/এন্টার/চিহ্নে শব্দের বানান অভিধানের সাথে মিলিয়ে ঠিক হয় এবং ওপরের সারিতে সাজেশন দেখায় (১০ নম্বর)। প্রতিটি নিয়ম পরীক্ষিত।

## ১. স্বর

| টাইপ | শব্দের শুরুতে / স্বরের পরে | ব্যঞ্জনের পরে (কার) |
|---|---|---|
| `o` | অ | (কিছু না, ব্যঞ্জন+অ) |
| `a` | আ | া |
| `i` | ই | ি |
| `ii` | ঈ | ী |
| `u` | উ | ু |
| `uu` | ঊ | ূ |
| `rrr` / `qr` | ঋ | ৃ |
| `e` | এ | ে |
| `oi` | ঐ | ৈ |
| `oo` | ও | ো |
| `ou` | ঔ | ৌ |

`o` ব্যঞ্জনের পরে কিছু বসায় না, কিন্তু যুক্তাক্ষর ভাঙে: `kotha` = কথা (ক্থ নয়)। এই অবস্থায় লেখার মধ্যে একটি **লাল `o`** মার্কার দেখা যায়; পরের অক্ষর চাপলেই সেটি সরে যায়, শব্দ পাকা হলে থাকে না।

## ২. ব্যঞ্জন

| টাইপ | অক্ষর | টাইপ | অক্ষর | টাইপ | অক্ষর |
|---|---|---|---|---|---|
| `k` | ক | `kh` | খ | `g` | গ |
| `gh` | ঘ | `nng` | ঙ | `c` | চ |
| `ch` | ছ | `j` | জ | `jh` | ঝ |
| `nnn` | ঞ | `tt` | ট | `tth` | ঠ |
| `dd` | ড | `ddh` | ঢ | `nn` | ণ |
| `t` | ত | `th` | থ | `d` | দ |
| `dh` | ধ | `n` | ন | `p` | প |
| `f / ph` | ফ | `b` | ব (শুধু স্বাধীন) | `bh / v` | ভ |
| `m` | ম | `y` | য় (স্বাধীন) | `z` | য |
| `r` | র | `l` | ল | `s` | স |
| `ss` | শ | `sss` / `qs` | ষ | `h` | হ |
| `x` | ক্ষ | `rr` | ড় | `rrh` | ঢ় |

- `y` সবসময় স্বাধীন য় (আগে বা পরের ব্যঞ্জনের সাথে জোড়া লাগে না, `b`-এর মতো): `hoy` = হয়, `dey` = দেয়, `noy` = নয়। য-ফলা ও য-র জন্য `z`।
- `r` = র, `rr` = ড়, `rrh` = ঢ়, `rrr` বা `qr` = ঋ/ৃ। তাই ড়ি/ড়ী সরাসরি লেখা যায়: বাড়ি = `barri`, ঘড়ি = `ghorri`, ঝড়ী = `jhorrii`। ঋ/ৃ: ঋষি = `rrrsssi`, কৃত = `krrrt`।
- `b` সবসময় আলাদা (স্বাধীন) ব দেয়, আগের অক্ষরের সাথে যুক্ত হয় না: `kb` = কব। যুক্ত ব (ব-ফলা) লিখতে `w` ব্যবহার করুন।
- `w` ব্যঞ্জনের পরে **ব-ফলা** (`sw` = স্ব, `dw` = দ্ব); শব্দের শুরুতে বা স্বরের পরে **ও** (`wjon` = ওজন)।
- **ন-এর পরিবার**: `n` = ন, `nn` = ণ, `nnn` = ঞ, `nng` = ঙ, `ng` = ং। ন + ন (ন্ন) লিখতে শিফট: `n⇧n` = ন্ন, `bhin⇧no` = ভিন্ন। একইভাবে ণ্ন = `nn⇧n`, ণ্গ = `nn⇧g`।

## ৩. চিহ্ন

| টাইপ | ফল |
|---|---|
| `ng` | ং (শুধু `ng`-তেই) |
| `qn` / `nnn` | ঞ (দুটোতেই একই) |
| `qw` | ঃ |
| `qq` | ঁ |
| `qt` | ৎ (সব জায়গায়) |
| `qk` | ৳ |
| `.` | । |
| `0-9` | ০-৯ |
| `,,` | হসন্ত + ZWNJ |
| শুধু `q` | q-ই থাকে |

**ং:** শুধু `ng`-তে হয়: `bangla` = বাংলা, `songsar` = সংসার।

**ঞ:** `nnn` আর `qn` দুটোতেই ঞ হয়; তালিকাভুক্ত জোড়ায় নিজে যুক্ত হয়: `jnnn` = `jqn` = জ্ঞ, অন্যত্র স্বাধীন: `kqn` = কঞ (জোর করতে `k⇧qn` = ক্ঞ)। ন্ন লিখতে `n⇧n`, ভিন্ন = `bhin⇧no` (শিফট)। ঙ লিখতে `nng` (`nngk` = ঙ্ক)।

**ঃ:** `qw` যেকোনো জায়গায় ঃ: `duqwkh` = দুঃখ, `monoqw` = মনঃ।

**ৎ:** `qt` স্বরের পরে, শব্দের শুরুতে এবং ব্যঞ্জনের পরেও ৎ দেয়: হঠাৎ = `hotthaqt`, জগৎ = `jogqt`, ভবিষ্যৎ = `bhobissszqt`। একমাত্র ব্যতিক্রম ত/ট-এর ঠিক পরে (সেখানে `q` শুধু বিভাজক)। তৎ লিখতে `toqt`।

## ৪. শিফট (⇧), `o` ও `q`

**মূল কথা:** কিবোর্ড "লোভী" (গ্রিডি) পদ্ধতিতে কাজ করে: লম্বা কী-ক্রম আগে মেলে (`tt` = ট, `nn` = ণ, `kh` = খ …) এবং **তালিকাভুক্ত ১৬৩টি** ব্যঞ্জন-জোড়া নিজে যুক্ত হয় (`kt` = ক্ত, `nd` = ন্দ)। বাকি জোড়া আলাদা থাকে (`kf` = কফ)। যেখানে এই স্বয়ংক্রিয় নিয়ম চাওয়া ফল দেয় না, শুধু সেখানে এই তিন কী:

| কী | কাজ |
|---|---|
| **যুক্ত** (বাংলায় শিফট কী, একবার ট্যাপ) | পরের কী-র স্বয়ংক্রিয় মিলন বন্ধ করে নিজের মতো বসায়: **ব্যঞ্জনের আগে = জোর করে যুক্ত**, **স্বরের আগে = স্বাধীন স্বর** |
| `o` | ব্যঞ্জনের পরে অ-ধ্বনি: কিছু লেখে না, কিন্তু জোড়া **যুক্ত হতে দেয় না**। শুরুতে/স্বরের পরে = অ |
| `q` | শুধু বিশেষ বর্ণ ও চিহ্ন |

### শিফট কীভাবে কাজ করে

- শব্দ লেখার মাঝে শিফট চাপলে শব্দের শেষে নীল **`s`** মার্কার দেখা যায় (ওপরের ইংরেজি ঘরে `⇧`)। পরের কী-তে কাজ হলে `s` চলে যায়।
- **একবারই কাজ করে:** বারবার চাপলেও একটিই।
- **Backspace** দিলে `s` মুছে যায়।
- শব্দের শুরুতে (লেখা ছাড়া) চাপলে কিছু হয় না। শিফটের পরে ব্যঞ্জন বা স্বর না এসে স্পেস/চিহ্ন এলে `s` কিছুই করে না।

**শিফট + ব্যঞ্জন = জোর করে যুক্ত**

| টাইপ | ফল | শিফট ছাড়া |
|---|---|---|
| `t⇧t` | ত্ত | `tt` = ট |
| `d⇧dh` | দ্ধ | `ddh` = ঢ |
| `n⇧n` | ন্ন | `nn` = ণ |
| `s⇧s` | স্স | `ss` = শ |
| `r⇧r` | র্র | `rr` = ড় |
| `k⇧f` | ক্ফ | `kf` = কফ |
| `k⇧kh` | ক্খ | `kkh` = কখ |
| `n⇧k` | ন্ক | `nk` = নক |
| `pr⇧k` | প্র্ক | `prk` = প্রক |

য় (`y`) শিফট দিলেও কখনো ফলা হয় না: `k⇧y` = কয়।

**শিফট + স্বর = স্বাধীন স্বর**

| টাইপ | ফল | শিফট ছাড়া |
|---|---|---|
| `bo⇧i` | বই | `boi` = বৈ |
| `ko⇧oo` | কও | `kooo` = কোঅ |
| `k⇧i` | কই | `ki` = কি |
| `k⇧a` | কআ | `ka` = কা |

### `o` — যুক্ত না করা

দুই ব্যঞ্জনের মাঝে `o` দিলে জোড়া আলাদা থাকে। তালিকাভুক্ত জোড়া নিজে যুক্ত হয়, তাই যুক্ত না চাইলে `o`: কতো = `koto` (`kto` = ক্তো), বাকস = `bakos` (`baks` = বাক্স)। ব্যঞ্জনের পরে `o` অদৃশ্য; শেষ কী হলে লাল `o` মার্কার দেখা যায়।

### `q` — শুধু বিশেষ বর্ণ ও চিহ্ন

`q` চাপলে সবুজ `q` মার্কার দেখা যায় (পরের অক্ষর এলে সরে যায়)।

| টাইপ | ফল | উদাহরণ |
|---|---|---|
| `qq` | ঁ | `caqqd` = চাঁদ, `cqqa` = চঁআ |
| `qw` | ঃ | `duqwkh` = দুঃখ |
| `qt` | ৎ | `hotthaqt` = হঠাৎ, `jogqt` = জগৎ |
| `qk` | ৳ | |
| `qn` | ঞ (তালিকাভুক্ত জোড়ায় যুক্ত, যেমন জ্ঞ) | `jqn` = জ্ঞ |
| `qr` | ঋ / ঋ-কার | `qrsssi` = ঋষি, `kqr` = কৃ, `mqrtzu` = মৃত্যু |
| `qs` | স্বাধীন ষ | `kqs` = কষ |
| `qx` | ক্স | `kqx` = কক্স |
| `qh` | স্বাধীন হ | `kqh` = কহ |
| `qz` | স্বাধীন য (য-ফলা নয়) | `kqz` = কয |
| `q.` / `q,` | ? / ! | `kq.` = ক? |

- `q` + অন্য কোনো অক্ষর দিলে `q` চলে যায়, কিছু করে না (`qj` = জ)। তাই `tqt` এখন ত্ত নয়, তত।
- পরপর সর্বোচ্চ ২টি `q` বসে।
- ব্যতিক্রম: ত/ট-এর পরে `qt`, ন/ণ-এর পরে `qn`, র-এর পরে `qr`, স/শ-এর পরে `qs` — এগুলোতে `q` শুধু বিভাজক।
- ঞ = `nnn`, ঙ = `nng` — এগুলোতে `q` লাগে না: `ponnnco` = পঞ্চ, `onngko` = অঙ্ক।
- `rrr` = ঋ/ঋ-কার, আগের মতোই।


### গ্রিডি মোড বন্ধ করলে (নন-গ্রিডি)

সেটিংসে "গ্রিডি মোড" সুইচ (ডিফল্টে চালু)। **বন্ধ** করলে:

- **কিছুই নিজে যুক্ত হয় না**; `র` ও `য` স্বাধীন (`kr` = কর, `kz` = কয)।
- **শিফট পোস্টফিক্স:** লেখার **পরে** শিফট চাপলে শেষ ব্যঞ্জনটি আগেরটির সাথে যুক্ত হয়; কারের পরে চাপলে কার স্বাধীন স্বর হয়। প্রতিটি জোড়ার পরে একবার করে শিফট (`bj⇧r⇧` = ব্জ্র)।
- দ্বিত্বে (`tt` = ট) মাঝে `o`: `tot⇧` = ত্ত। `o`-এর পরে শিফট = স্বাধীন অ।
- `qn`, `qs` স্বাধীন; `jqn⇧` = জ্ঞ।

| টাইপ | ফল |
|---|---|
| `km⇧` | ক্ম |
| `kr⇧` | ক্র |
| `kz⇧` | ক্য |
| `rk⇧` | র্ক |
| `tot⇧` | ত্ত |
| `bj⇧r⇧` | ব্জ্র |
| `ka⇧` | কআ |
| `ko⇧` | কঅ |
| `jqn⇧` | জ্ঞ |

গ্রিডি **চালু** থাকলে শিফট আগের মতো ব্যঞ্জনের **আগে** (`t⇧t` = ত্ত, `bo⇧i` = বই)। গ্রিডি চালুতেও `qn` শুধু তালিকাভুক্ত জোড়ায় নিজে যুক্ত হয় (`jqn` = জ্ঞ), অন্যত্র স্বাধীন (`kqn` = কঞ; জোর করতে `k⇧qn` = ক্ঞ)।

### কোনটি কখন?

| অবস্থা | কী |
|---|---|
| কিছু যুক্ত হচ্ছে না, যুক্ত চাই | শিফট (`k⇧f`) |
| ত্ত, দ্দ, দ্ধ, ন্ন, স্স, র্র (একই কী-র ফাঁদ) | শিফট (`t⇧t`) |
| কার বসছে, স্বাধীন স্বর চাই | শিফট (`bo⇧i`) |
| কিছু যুক্ত হচ্ছে, চাই না | `o` (`koto`) |
| ৎ ঃ ঁ ৳ ঋ ষ ক্স হ য ঞ ! ? | `q` |
| হসন্ত নিজে (ZWNJসহ) | `,,` |

> পুরনো অভ্যাস চলে: `boqi` = বই, `koqoo` = কও (`q` চলে যায়, স্বর আগেই স্বাধীন) — তবে নতুন নিয়মে `bo⇧i` লিখুন।

## ৫. র-ফলা, রেফ, য-ফলা, ব-ফলা

- **র-ফলা**: ব্যঞ্জনের পরে সরাসরি `r`: `pr` = প্র, `kr` = ক্র, `str` = স্ত্র, `prem` = প্রেম।
- **রেফ**: শুরুতে বা স্বরের পরে `r` + ব্যঞ্জন নিজে থেকেই: `durga` = দুর্গা, `orth` = অর্থ। ব্যঞ্জনের পরে: `dhorm` = ধর্ম (`o` দিয়ে)।
- **য-ফলা**: ব্যঞ্জনের পরে `z`: `kz` = ক্য, `bidza` = বিদ্যা, `sotz` = সত্য। `zz` = য্য।
- **র‍্য (র-এর সাথে য-ফলা)**: শব্দের শুরুতে `rz` → র‍্যাব = `rzab`। অন্য জায়গায় `rqz`। র-ফলার পরে য-ফলা চলে: ব্র্যান = `brzan`। রেফ + য লিখতে সাধারণ `rz`: কার্য = `karz`, সূর্য = `suurz`।
- **স্বরবর্ণে য-ফলা**: অ-এর (বা যেকোনো স্বরবর্ণের) পরে `z` = য-ফলা: অ্যাপ = `ozap`। য-ফলা না চাইলে `q` দিয়ে ভাঙুন: অযথা = `oqzotha`।
- **ব-ফলা**: ব্যঞ্জনের পরে `w`: `sw` = স্ব, `dw` = দ্ব। অন্যত্র `w` = ও।

**পরের-কী ইঙ্গিত:** শব্দ লেখার সময় প্রতিটি অক্ষর-কী-র গায়ে নীল ছোট লেখায় দেখায় ওই কী এরপর চাপলে কী আসবে। যেমন `k` চাপলে `h`-এ খ, `a`-তে কা, `r`-এ ক্র, `z`-তে ক্য, `w`-তে ক্ব। কার, ফলা, যুক্তাক্ষর, দুই-তিন অক্ষরের ব্যঞ্জন সব ক্ষেত্রেই এটি কাজ করে। `q` সক্রিয় থাকলে যেসব কী-র ফল `q`-এর কারণে বদলায় সেগুলোর ইঙ্গিত সবুজ; শিফট অপেক্ষায় থাকলে ইঙ্গিতে জোর-করা ফল দেখায়। শব্দ শেষ হলে (স্পেস/চিহ্ন) ইঙ্গিত চলে যায়।

**২ সেকেন্ড চেপে ধরলে (এডিট কমান্ড):** নিচের কী-গুলো ২ সেকেন্ড চেপে ধরলে অক্ষরের বদলে কমান্ড চলে। ধরে রাখার সময় কী-র নিচে একটা লাইন ভরতে থাকে, আর প্রতিটি কী-র নিচের বাম কোণে ছোট করে কমান্ডের নাম লেখা আছে। ২ সেকেন্ডের আগে ছেড়ে দিলে সাধারণ অক্ষর বসে। চলমান বাংলা শব্দ আগে পাকা হয়, তারপর কমান্ড চলে।

- শব্দ কী-র ধরন অনুযায়ী আলাদা: সাধারণ কী, স্পেস, মোছা (⌫), এন্টার। মোছা চেপে ধরে রাখলে প্রতিবার মোছার সাথে শব্দ হয়।
- ফোন সাইলেন্ট বা ভাইব্রেট মোডে থাকলে শব্দ বাজে না (ভাইব্রেশন সুইচ আলাদা)।
- ২ সেকেন্ড চেপে ধরার কমান্ড (কাট/কপি ইত্যাদি) পূর্ণ হলে কম্পন দ্বিগুণ হয়।
- মাত্রা: যে ফোনে কম্পনের জোর নিয়ন্ত্রণ করা যায় সেখানে জোর বদলায়; অন্য ফোনে কম্পনের সময় বদলায়।

**কিবোর্ডের উচ্চতা:** অ্যাপ খুলে "কিবোর্ডের উচ্চতা" স্লাইডার দিয়ে ৭০% থেকে ১৫০% পর্যন্ত ঠিক করুন; পরের বার কিবোর্ড খুললে কাজ করবে।

অ্যাপের সেটিংসে "প্রিভিউ প্যানেল" চালু করলে (ডিফল্টে বন্ধ) নম্বর সারির ঠিক ওপরে, মাঝখানে একটি ছোট ঘরে চলমান শব্দের **ইংরেজি অক্ষরগুলো** দেখায়: `kotha` লিখলে ঘরে `kotha`, লেখায় কথা। স্পেস বা দাঁড়ি/এন্টার দিলে ঘর খালি হয়ে যায় এবং নতুন শব্দের জন্য তৈরি থাকে। কিবোর্ড পরের বার খুললে বদল কাজ করে।

## ১২. টাইপিং সাউন্ড

সেটিংসে "টাইপিং সাউন্ডের ধরন" থেকে বাছুন: ক্লিক (সাধারণ) · টাইপরাইটার · মেকানিক্যাল কিবোর্ড · বাবল পপ · পানির ফোঁটা · কাঠের টোকা · রেট্রো বিপ। বাছার সঙ্গে সঙ্গে নমুনা শোনা যায়। সাধারণ কী, স্পেস, মোছা ও এন্টারের আওয়াজ আলাদা। শব্দ ও কম্পনের মাত্রা এবং চালু/বন্ধ আলাদাভাবে ঠিক করা যায়।
